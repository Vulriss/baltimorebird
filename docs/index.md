# Baltimore Bird

Baltimore Bird est une plateforme web d'analyse de séries temporelles automobiles :
exploration de mesures MF4 et CAN bus, construction de tableaux de bord réutilisables,
export de rapports, scripts Python et conversion de fichiers.

Cette documentation couvre l'utilisation de l'outil depuis un navigateur. Elle ne
couvre pas l'installation ou l'administration du serveur, voir le `README` du dépôt
pour ce sujet.
