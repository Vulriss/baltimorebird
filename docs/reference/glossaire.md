# Glossaire

**MF4**
: Format de fichier ASAM MDF version 4, standard de l'industrie automobile pour
  l'enregistrement de mesures temporelles.

**DBC**
: Fichier de description de base CAN, associant les identifiants de trames CAN
  brutes à des signaux nommés et décodés.

**Session lazy (paresseuse)**
: Mode de chargement dans lequel seules les métadonnées et la liste des canaux d'un
  fichier sont chargées à l'ouverture ; les données de signal ne sont récupérées
  qu'au moment où elles sont réellement affichées.

**LTTB**
: Largest Triangle Three Buckets, algorithme de sous-échantillonnage utilisé pour
  réduire le nombre de points tracés tout en préservant la forme visuelle du signal.

**Disposition (layout)**
: Agencement sauvegardé d'onglets, de graphiques et de signaux sélectionnés dans
  l'espace EDA.

**Variable calculée**
: Signal dérivé, défini par une formule appliquée à un ou plusieurs signaux
  existants d'un fichier.

**Bac à sable (sandbox)**
: Environnement d'exécution isolé et restreint utilisé pour exécuter les scripts
  Python de l'espace Scripts en toute sécurité.

**Mode invité**
: Mode d'utilisation sans compte, avec session temporaire et fonctionnalités
  limitées.
