# Reports

L'espace Reports permet de consulter et d'exporter les analyses générées à partir des
tableaux de bord. Il est réservé aux comptes utilisateur.

## Liste des rapports

La liste des rapports (`reportsList`) affiche l'ensemble des analyses générées, avec
un compteur en tête de liste et un champ de recherche pour filtrer par nom. Une liste
vide affiche un message d'invite.

## Visualiseur

La sélection d'un rapport dans la liste l'ouvre dans le visualiseur intégré, qui
affiche son contenu tel qu'il a été généré, avec le nom du rapport rappelé en
en-tête.

## Suppression

La suppression d'un rapport passe par une confirmation explicite (fenêtre modale
rappelant le nom du rapport concerné), afin d'éviter une suppression accidentelle.
Cette action est irréversible.
