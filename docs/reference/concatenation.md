# Concaténation

L'espace Concaténation permet de fusionner plusieurs fichiers MF4 en un seul fichier
continu. Accessible en mode invité comme en mode compte.

## Étapes

1. Ajouter les fichiers MF4 à concaténer dans la liste. L'ordre d'ajout détermine
   l'ordre de concaténation ; il peut être ajusté avant de lancer le traitement.
2. Renseigner le nom du fichier de sortie.
3. Lancer la concaténation.

## Suivi de progression

Comme pour la conversion, la concaténation s'exécute de manière asynchrone, avec une
barre de progression et un pourcentage d'avancement. Un résumé des statistiques du
fichier résultat (nombre de canaux, durée totale) est affiché à l'issue du
traitement.

## Cas d'usage typique

La concaténation est utile lorsqu'un même essai a été enregistré sur plusieurs
fichiers consécutifs (par exemple en raison d'une taille maximale de fichier côté
outil d'acquisition), et qu'une analyse continue sur l'ensemble de l'essai est
nécessaire.
